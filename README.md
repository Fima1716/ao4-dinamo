## Илье — коротко

- Правим `final/`. Стили наследуются: `final/style.css` → `variant2-full/style.css` → `variant2/style.css`. Трогаешь базу — проверь все версии.
- Первый экран обёрнут в `.v1` и живёт на своих переменных (шрифт Onest). Правила для него пиши с префиксом `.v1`.
- Локально: `python3 -m http.server 8765`, затем `localhost:8765/final/`.
- Пуш в `main` сам выкладывает сайт на сервер. Сломанная вёрстка уедет в прод — смотри перед пушем на 1440×900 и 390×844.
- Тексты на сайте правятся прямо в браузере: добавь `?admin` к адресу, пароль спроси у Ефима. Правки хранятся по пути элемента в DOM, поэтому **переделка структуры блока сбрасывает его тексты**.
- Подробные правила, данные клиники и ограничения по медрекламе — в [AGENTS.md](AGENTS.md).

## Промпт для агента Ильи для коммита

```
Коммить по схеме: тип(область): описание в повелительном наклонении.

Типы: feat, fix, style, content, refactor, perf, docs, chore.
Области: final, variant1, variant2, variant2-full, hero, quiz, editor, api, assets, ci.

Правила:
— строчные буквы, без точки в конце, до 72 символов;
— повелительное наклонение: «добавь», «почини», «убери»;
— описание на русском;
— один коммит — одно логическое изменение, не мешай контент и вёрстку;
— тело пиши, только если неочевидно «почему», и объясняй причину, а не диффы;
— никаких секретов, паролей и ключей в коммите.

Примеры:
fix(hero): верни пропорции картинки протеза на мобильных
content(team): обнови стаж врачей по данным клиники
style(variant2): сделай строку про импланты жирнее
```
