# All Smiles — лендинг центра имплантации на Динамо

Продающий лендинг стоматологии (имплантация All-on-4 у метро Динамо): главная,
страницы врачей, онлайн-редактор текстов для клиента и приём заявок с форм.

## Стек

Статический сайт: HTML + CSS + ванильный JS. Ни сборки, ни npm, ни фреймворков —
открыл файл, поправил, сохранил. Бэкенд — один Node-файл без зависимостей
(`api/server.js`, Node 18+), нужен только для админки: правки страниц, настройки,
приём заявок.

## Структура

```
index.html        главная — тут весь основной текст сайта
style.css         первый экран (.v1) + базовые стили всей страницы
design.css        шрифты, цвета, шапка, кнопки
sections.css      секции ниже первого экрана
mobile.css        мобильная версия (<760px): таб-бар, сторис, шторки
script.js         формы, квиз, модалка, калькулятор рассрочки, маршрут
mobile.js         мобильный слой (таб-бар, сторис)

vrachi/<slug>/    страницы врачей; vrachi/vrachi.css — их общий стиль
admin/            панель администратора (заявки, SEO, метрика, колтрекинг)
policy/           политика обработки персональных данных
docs/             образец договора (PDF)
thanks/           страница «заявка принята»
sitemap.xml       карта сайта

assets/           картинки (doctors, cases, route, brands, render…)
js/editor.js      редактор текстов/фото — подключён на всех страницах
api/server.js     бэкенд админки (см. «Бэкенд»)
```

Стили подключаются по порядку: `style.css` → `design.css` → `sections.css`,
поверх для узких экранов — `mobile.css`. Чем ниже в списке, тем выше приоритет.
Первый экран живёт в пространстве `.v1` (у него свои шрифты и цвета) — правила для
него пиши с префиксом `.v1`, иначе они протекут на остальную страницу.

## Запуск локально

```bash
python3 -m http.server 8765      # или любой статик-сервер
```

Открыть `http://localhost:8765/`. Формы и админка ходят в `/api` — без запущенного
бэкенда (ниже) локально они не работают, но смотреть вёрстку это не мешает.

## Деплой сайта

Сайт — просто статика, сборка не нужна. Выложи содержимое репозитория на любой
веб-сервер (nginx, Apache, статик-хостинг), кроме служебного: `api/`, `.git/`,
`*.md`.

Единственный нюанс — кэш: браузеры держат старые css/js. При обновлении
стилей/скриптов меняй версию в ссылке в `index.html` — `style.css?v=2`,
`script.js?v=3` (так же для картинок, если заменил их под старым именем).

## Бэкенд (админка)

`api/server.js` — Node без зависимостей, слушает `127.0.0.1:$PORT` (по умолчанию
8791). Поставь его за тем же nginx и проксируй на него `/api/` и `/robots.txt`:

```nginx
location ^~ /api/      { proxy_pass http://127.0.0.1:8791/; proxy_set_header Host $host; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; }
location = /robots.txt { proxy_pass http://127.0.0.1:8791/robots.txt; }
```

`^~` обязателен — иначе `/api/uploads/*.webp` перехватит regex статики картинок.

Запуск любым менеджером процессов (systemd, pm2, docker):

```bash
PORT=8791 EDITOR_PASSWORD='…' node api/server.js
```

Данные сервер держит рядом с собой в `data/` (путь меняется через `DATA_DIR`):
`page_*.json` — правки по странице, `settings.json` — SEO/метрика/robots,
`leads.json` — заявки, `data/uploads/` — загруженные фото.

Конфиг — через переменные окружения (или `data/secrets.json`); в репозитории
секретов нет:

| Переменная | Зачем |
|---|---|
| `EDITOR_PASSWORD` | пароль входа в админку (не задашь — сгенерится временный и упадёт в лог) |
| `PORT`, `DATA_DIR` | порт и папка данных |
| `SMTP_HOST` / `PORT` / `USER` / `PASS` / `FROM` / `TO` | дублирование заявок на почту |
| `TG_TOKEN`, `TG_CHAT` | дублирование заявок в Telegram |

## Админка

- Панель — `/admin/` (вход по паролю `EDITOR_PASSWORD`): заявки с выгрузкой в CSV,
  SEO-теги, robots.txt, код Яндекс.Метрики, колтрекинг, свои скрипты в `<head>`.
- Правка прямо на странице — добавь `?admin` к адресу: тексты, замена фото,
  перестановка блоков кнопками ↑/↓.

Правки клиента хранятся на сервере в `page_*.json`, а не в файлах сайта, и привязаны
к положению элемента в разметке. Сильно переделаешь структуру блока — правки, что
клиент вносил в нём, вернутся к исходным. Ключи правок исторически в пространстве
`/final/` (в разметке `data-page="/final/…"`) — не меняй, на этом держатся уже
сохранённые правки.

## Тексты: это медицина

Реклама медуслуг. Нельзя «гарантируем результат», «без боли», «навсегда»,
«лучшие»; в подвале обязательна строка про противопоказания, у форм — согласие на
обработку данных со ссылкой на политику; тире короткое «–». Проверенные данные
клиники (телефон, адрес, цены, врачи, акции) — в `AGENTS.md`.
